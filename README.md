# Iris Multi-Class Classification

An interactive machine-learning application that predicts
Iris flower species using four flower measurements.

## Flower species
- Setosa
- Versicolor
- Virginica

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Plotly
- Joblib

## Project files
- app.py: Streamlit dashboard
- iris_best_model.pkl: Trained model and preprocessing objects
- requirements.txt: Python dependencies

## Run locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
streamlit run app.py
```

The dashboard uses the saved model package and displays
illustrative flower reference photographs.

## Deployment
This application can be deployed using Streamlit Community Cloud
by connecting this GitHub repository.
